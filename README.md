# DON'T LOOK BACK — Godot v0.1

A small first-person horror prototype built for Godot 4.x.

## Playable features
- WASD first-person movement
- Mouse look
- F toggles flashlight
- E interacts with the door
- Dark hallway made only from built-in Godot geometry
- Light flicker scare
- A shadow figure appears behind the player and vanishes when looked at
- End-of-prototype trigger

## Open in Godot
1. Clone this repository to your PC.
2. Open Godot 4.x.
3. In Project Manager choose **Import**.
4. Select `project.godot` from the cloned folder.
5. Choose **Import & Edit**.
6. Press **F5** or the Play button.

No external assets or plugins are required.

## Controls
- W A S D — Move
- Mouse — Look
- E — Interact
- F — Flashlight
- Esc — Release/capture mouse

## GitHub workflow
This repository is the main source for the game. After future updates, pull the latest changes into the same local folder and open the existing Godot project; no re-import from ZIP is required.
