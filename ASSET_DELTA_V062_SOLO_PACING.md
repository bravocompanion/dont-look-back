# Don't Look Back v0.62 — Asset Delta

Scope: solo horror pacing + persistent Research Facility consequences.

## Mandatory new runtime assets

**NONE.**

All v0.62 gameplay is functional with the current procedural/HUD fallbacks. No production art/audio is required for the new rules to parse, load, or remain playable on desktop/mobile.

## New P1 recommended assets

### Horror pacing / solo Darkness

- subtle UNEASE ambience layer that can fade in without becoming a jump-scare cue;
- STALK pressure pulse / distant environmental one-shots;
- HUNT transition sting shared carefully with the existing Darkness identity;
- post-encounter RECOVERY release tail / room-tone return;
- low-cost mobile mix variants with no requirement for expensive screen-space VFX.

### Research consequence — RESCUE PRIORITY

- short survey-team radio acknowledgement;
- protected Ranger-shelter decompression/all-clear layer;
- regroup confirmation tone when the Rescue recovery bonus is active;
- optional subtle generator/cabin response accent rather than a large HUD banner.

### Research consequence — ANOMALY PRIORITY

- signal-analysis stinger for UNEASE → STALK transitions;
- compact threat-analysis HUD icon/state glyphs for CALM / UNEASE / STALK / HUNT / RECOVERY;
- restrained data-noise layer for confirmed HUNT;
- recovery-analysis confirmation tone.

Threat-state readability must remain legible at the existing 1280×720 target and on small touch screens. Prefer audio + compact iconography over persistent text walls or full-screen interference. New audio should have conservative simultaneous-voice counts for mobile.
