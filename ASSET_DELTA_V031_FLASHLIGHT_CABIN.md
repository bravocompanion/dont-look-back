# Asset Delta — v0.31 Flashlight + Ranger Cabin

## Flashlight

No new asset is mandatory for the gameplay update. Production polish still benefits from:

- first-person ranger flashlight model
- world/remote-player flashlight model for multiplayer
- flashlight lens / cookie texture suitable for the wider 36.4 degree cone
- cheap mobile beam treatment without particles
